# Game Manager

This project creates a skeleton for a basic game. It includes the following features: 
- Adding and deleting players/monsters with specific attributes such as health and score.
- Maintaining an active menu at each stage.
- Storing characteristics for offline access.

---

This project is designed to utilize basic Object Oriented Programming principles such as:
- Inheritance
- Polymorphism
- File I/O
- Exception handling

---

Potential Use Cases: 
1. Learning Java
2. Upscale project by addding art for game scences, players, and enemies.
3. Add basic movement scripts for a 2-D Platformer
